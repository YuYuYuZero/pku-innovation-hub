# 创新学社智能体系 · 产品原型

北大创新学社智能体系的高保真产品原型：**学社资产（资源 + 知识）· 工具（AI 助手）· 社区（北大同学的讨论、活动、精选，以及重点的创业板块）**。

在线预览：https://yuyuyuzero.github.io/pku-innovation-hub/

页面右下角的“原型目录”可以切换页面；勾选“显示编号标注”（或在地址后加 `#anno`）会显示与产品文档对应的编号。

| 页面 | 文件 |
|---|---|
| 首页 | `index.html` |
| 资源库 | `resources.html` |
| 资源详情 | `resource_detail.html` |
| 录入资源 | `resource_new.html` |
| 批量导入 | `upload.html` |
| 知识库 | `kb.html` |
| 文档阅读与问答 | `kb_doc.html` |
| 工作台 | `workbench.html` |
| AI 助手 | `assistant.html` |
| 助手技能 | `skills.html` |
| 讨论 | `community.html` |
| 活动 | `events.html` |
| 录入活动 | `event_new.html` |
| 活动申报审批 | `activity_review.html` |
| 精选 | `featured.html` |
| 创业 · 项目 | `projects.html` |
| 创业 · 项目详情 | `project_detail.html` |
| 创业 · 投资人与机构 | `investors.html` |
| 审核与管理 | `admin.html` |
| 登录与身份 | `login.html` |
| 手机与飞书 | `mobile.html` |

公共样式与脚本在 `assets/`：`app.css`（设计系统）、`app.js`（侧边栏、顶栏、原型目录）、`icons.js`（Lucide 图标）。

> 原型中的人物、机构和数据均为示例。
