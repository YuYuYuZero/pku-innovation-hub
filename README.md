# 创新学社智能体系 · 产品原型

北大创新学社智能体系的高保真产品原型：**学社资产（资源 + 知识 + 工作台）· 工具（AI 助手）· 社区内测版（讨论、活动）· 平台管理（会长团权限）**。精选、创业板块暂不开放，页面保留在原型目录的“暂不开放”下。

在线预览：https://yuyuyuzero.github.io/pku-innovation-hub/

页面右下角的“原型目录”可以切换页面；勾选“显示编号标注”（或在地址后加 `#anno`）会显示与产品文档对应的编号；地址后加 `#dlg-<名字>` 可以直接打开某个弹窗（如 `workbench.html#dlg-apply`）。

> 原型中的人物、机构和数据均为示例。
