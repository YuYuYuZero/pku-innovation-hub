# 创新学社智能体系 · 产品原型

北大创新学社智能体系的高保真产品原型：**学社资产（资源 + 知识 + 工作台）· 工具（AI 助手）· 社区（活动）· 审核与管理（按身份开放）**。讨论、精选、创业板块暂不开放，页面保留在原型目录的“暂不开放”下。

在线预览：https://yuyuyuzero.github.io/pku-innovation-hub/

页面右下角的“原型目录”可以切换页面；勾选“显示编号标注”（或在地址后加 `#anno`）会显示与产品文档对应的编号；地址后加 `#dlg-<名字>` 可以直接打开某个弹窗（资源审核等页面仍保留相应弹窗）。

## 与 app 一致的功能范围

工作台开放「任务跟进 / 贡献与权益」：骨干上报与更新 TODO、完成后填实际工时及成果；部长 / 会长团在管理范围内分配五档系数（1.0–1.4）、确认或完整校准积分。校准原因必填，保留原始上报与调整前后值。只有已确认贡献计入权益参考，不做公开排名或自动兑换。演示操作保存在当前浏览器，可切换身份继续操作。

活动申报审批和独立积分申诉流程继续暂停，旧活动申报链接显示暂停提示，原资源审核深链跳转到 `resource_review.html`。资源审核独立保留；活动录入放在活动页，学社主办活动也可直接收录，报名和组织安排按活动通知办理。

骨干及以上的“学社资产”分组显示内部资产锁；普通会员隐藏无权限入口和锁图标：资源库与工作台限骨干，知识库对成员按每份文档的可读 / 读写范围开放。分组锁不改变实际权限；本仓库是静态交互原型，真实登录和权限由 app 实现。

知识库当前支持文件夹、上传、预览 / 下载、版本、备注记录和共享权限。检索匹配名称、备注和标签；全文检索、RAG 问答、飞书机器人尚未实现。手机与飞书页的相关画面已标为未来方案。

## 首页、收藏与想法反馈

首页把近期活动和资料更新合并到「学社动态」标签区；工作台导航使用完整图标。侧栏「我的收藏」及活动页同名标签可查看收藏，支持收藏、取消和刷新后找回，包括往期活动。

想法抽屉可直接填写「想法标题」「想法内容」，提交后展开查看并继续补充；AI 使用场景为选填。关闭抽屉保留本次页面草稿，刷新清空。已提交的想法、回复和收藏按演示身份保存在当前浏览器，不会发送给真实处理人；app 使用数据库保存和权限隔离。

## 本地验证

本原型无需环境变量或 OSS。用 `python3 -m http.server 8080 --bind 127.0.0.1` 预览。知识库页面加 `?storage=unavailable` 可检查文件存储不可用时的提示和上传禁用状态。运行 `npm ci && npm test` 检查导航、角色范围和页面链接，并用本机 Chrome 演示上报 → 确认 → 完整校准 → 权益 → 复用；缺少 Chrome 时明确跳过浏览器部分。截图保存在被忽略的 `data/screens/`。

实际文件上传与权限测试在相邻 app 仓库：`npm run dev:local` 启动纯本地环境；`npm run dev:local -- --keep` 将数据库和文件保存在 `data/local/`；`npm run build && npm test` 跑隔离测试。本地环境和测试边界见 app 的 `docs/02-技术架构与依赖.md`、`docs/03-开发与测试.md`、`docs/04-测试用例.md`。

可从登录页选择 A–F 六种演示身份，也可加 `?role=member` / `?role=backbone` / `?role=minister` / `?role=president` / `?role=maintainer` / `?role=outsider`，切页保留身份。邮箱认证入口暂时隐藏。
